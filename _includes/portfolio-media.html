{%- comment -%} Portfolio media renderer — single source of truth for how a media item looks. Tolerant by design: it inspects both the declared `type` and the `src`/`html` so the site renders correctly even when the upstream data is imperfect (e.g. a YouTube watch URL tagged `type: video`). Params: include.media — list of media maps: {type, src, html, label, alt, poster} include.title — item title (used for alt / aria text) include.limit — optional; render at most N media (used for compact cards) {%- endcomment -%} {%- if include.limit -%}{%- assign _limit = include.limit | plus: 0 -%}{%- else -%}{%- assign _limit = 9999 -%}{%- endif -%} {%- assign _shown = 0 -%} {%- for m in include.media -%} {%- if _shown >= _limit -%}{%- break -%}{%- endif -%} {%- assign _shown = _shown | plus: 1 -%} {%- comment -%} resolve a usable src (leave absolute URLs untouched, prepend baseurl for local paths) {%- endcomment -%} {%- assign _src = "" -%} {%- if m.src -%} {%- if m.src contains "://" -%}{%- assign _src = m.src -%}{%- else -%}{%- assign _src = m.src | relative_url -%}{%- endif -%} {%- endif -%} {%- comment -%} detect YouTube / Vimeo ids from the raw src {%- endcomment -%} {%- assign _yt = "" -%} {%- assign _vimeo = "" -%} {%- if m.src contains "youtu.be/" -%}{%- assign _yt elsif m.src contains "youtube.com/embed/" -%}{%- assign _yt = m.src | split: "/embed/" | last | split: "?" | first -%} {%- elsif m.src contains "youtube-nocookie.com/embed/" -%}{%- assign _yt = m.src endif -%} {%- comment -%} infer a fallback type from the file extension when needed {%- endcomment -%} {%- assign _low = m.src | downcase -%} {%- assign _type = m.type -%} {%- unless _type -%} {%- if
